### 🧠 Architecture
WiFi Router (RSSI Source) -> Kali Linux (wlan0 / Demo Mode) -> WebSocket Server (server.py) -> Live Radar UI (Live_room.html) -> Human Movement Detection

### ⚙️ How to Run
1. `pip install -r requirements.txt`
2. `python3 server.py`  (Terminal 1)
3. Open `Live_room.html` in browser (Terminal 2) -> `xdg-open Live_room.html`

### ✨ Features
- No camera needed
- Real-time RSSI variance analysis
- 360° rotatable radar
- 2 Targets tracking
- Demo mode for presentation
